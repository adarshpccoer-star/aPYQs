## About

**aPYQs** is a mobile application built with React Native that helps students access and manage Previous Year Question Papers (PYQs) easily.

The app provides a simple and user-friendly interface to browse PYQs and prepare effectively for exams.

---

## Features ✨

- 📚 Browse Previous Year Question Papers
- 🔍 Easy navigation and search
- 🎨 Theme support
- ⚡ Fast and smooth React Native experience
- 📱 Android APK release available

## Installation (Development)

Clone the repository:

```bash
git clone https://github.com/adarshpccoer-star/aPYQs.git
```

Go to project folder:

```bash
cd aPYQs
```

Install dependencies:

```bash
npm install
```

Start Metro bundler:

```bash
npm start
```

Run Android:

```bash
npx react-native run-android
```

---

## Build APK

Generate release APK:

```bash
cd android
./gradlew assembleRelease
```

APK location:

```
android/app/build/outputs/apk/release/app-release.apk
```
